# 灼兆 ZhuoZhao

以楚地巫祝与祭祀文化为题材的游戏。本仓库用于分发 **V44 Windows 运行版**，当前不包含 Unity 源工程。

## 下载与运行

前往 [Releases 发行版](https://github.com/vandawnlab/ZhuoZhao/releases/latest)，下载附件 **ZhuoZhao_V44_Windows.zip**。

1. 将整个压缩包解压。
2. 双击 `启动游戏.cmd` 或 `ZhuoZhao_V44.exe`。
3. 保留程序旁的 `ZhuoZhao_V44_Data`、`UnityPlayer.dll`、`MonoBleedingEdge` 等全部文件，不要只复制 EXE。

发行页自动生成的 `Source code` 压缩包仅包含仓库说明文件，游戏运行包请下载名称中带有 `Windows` 的附件。

## 运行环境

- 64 位 Windows 10 或 Windows 11。
- 显卡支持 DirectX 11。
- 无需安装 Unity。

## 基本操作

| 操作 | 按键 |
| --- | --- |
| 移动 | WASD |
| 跑步 | 双击 W |
| 观察 | 鼠标 |
| 交互 | E |
| 显示或推进对话 | 空格 |
| 背包 | Tab |
| 研学笔记 | J |
| 地图与任务 | M |
| 在祭场询问司命 | Q |
| 关闭界面或暂停 | Esc |

展品详情中可拖动旋转、用滚轮缩放，阅读后点击收录。外围八柜的参观顺序自由，全部收录后再前往中央龟甲；壁画详细阅读可自行选择。

祭场需完成问卜、收集并安置三件礼器、行乐，再靠近中央祭坛并将准星对准祭坛表面，按 E 献礼祝告。

## V44 说明

- 调整九座展柜的玻璃侧板与顶盖，保留闭合的细顶边。
- 返馆后先查看凤鸟挂饰，完成后可继续参观或从出口离开。
- 调整祭典星空的短弧、缓慢转动与夜空渐变效果。
- 调整出口墙饰与墙面的间距，修复视角移动时的闪烁。

游戏进度自动保存至当前 Windows 账户的用户数据目录，V44 使用独立进度文件 `v44-progress.json`。完整版本说明与试玩说明随运行包提供。
